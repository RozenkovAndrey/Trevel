# Lycian Way small-group travel website

## Status

Photo assets are prepared for website development.

## Photo assets

- `images/` contains the production web assets, including separate desktop and mobile HERO images.
- `photo-data/` contains the manifest, TOP-10 selection and MISSING.md. Resolve `web_filename` paths relative to `images/`.
- `photo-licenses/` contains external photo licenses and attribution for the future Photo Credits page.
- Originals, enhanced masters, quality checks and the source archive are kept outside Git. Master paths in the manifest record provenance.

## Important

Use the manifest to choose images and preserve attribution. Consult MISSING.md before assigning photos to sections. Use genuine accommodation photos for each named property and avoid unrelated internet photos.
